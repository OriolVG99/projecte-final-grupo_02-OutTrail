# OutTrail - Backend

Aquesta carpeta conté l'API del projecte OutTrail (Node.js + Express).

## Com executar

1. Instal·la les dependències:
   npm install

2. Configura el teu arxiu `.env`:
   Copia l'arxiu `.env.exemple` a un nou arxiu `.env` i omple les dades.

3. Executa en mode desenvolupament:
   npm run dev

El servidor estarà disponible a `http://localhost:4000`.
