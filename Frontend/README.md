# OutTrail - Frontend

Aquesta carpeta conté el codi font de la interfície d'usuari (React + Vite).

## Com executar

1. Instal·la les dependències:
   npm install

2. Configura el teu arxiu `.env`:
   Copia l'arxiu `.env.exemple` a `.env` i afegeix la teva clau d'API.

3. Executa en mode desenvolupament:
   npm run dev

3. Obre [http://localhost:5173](http://localhost:5173) al navegador.

**Nota**: Assegura't que el [Backend](../Backend) estigui funcionant perquè l'aplicació pugui carregar dades.
